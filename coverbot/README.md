# Бот подбора кавер-групп — MVP

Telegram-бот: продюсер описывает задачу своими словами → получает 3–5 подходящих кавер-групп с ценой и видео.
Группы сами заполняют анкету, админ модерирует. ТЗ — в документе «ТЗ: Telegram-бот подбора кавер-групп (MVP)».

## Что уже работает

- **Анкета группы** (16 шагов, в основном кнопками): название, город, выезд, состав, инструменты, жанры, описание,
  цены «от» для частного события / корпоратива / Нового года, формат программы, звук, доп. услуги, видео, контакты,
  превью карточки, согласие на публикацию → модерация.
- **Поиск для продюсера**: свободный текст → разбор нейросетью (Claude Haiku) → уточнение города и бюджета кнопками →
  фильтр + скоринг → карточки с пояснением «почему подходит» → «Показать контакт» (лид) → «Рекомендую».
  Любое следующее сообщение уточняет запрос («подешевле», «а на Новый год?»).
- **Если ничего не нашлось** — бот показывает ближайшие по цене варианты или снимает требование к инструментам.
- **Админ** (ID из `ADMIN_IDS`): новые анкеты приходят с кнопками «Одобрить / Отклонить»,
  команды `/pending`, `/stats`, `/export` (CSV всей базы), `/tvrec <id> [tg_id]` — рекомендация резидента «Тут все».
- **Актуальность цен**: раз в 90 дней бот спрашивает группу, актуальны ли цены (кнопки «Цены актуальны» /
  «Обновить анкету»); не ответили — повторит через 30 дней. Свежие цены поднимают группу в поиске.
- **Импорт «Тут все»** (по договорённости с владельцем): `python -m app.importer data/tutvse.csv` →
  черновики + `data/invite_links.csv` с персональными ссылками. Музыкант переходит, дозаполняет, даёт согласие.
- **Без ключа Anthropic** бот тоже работает: включается простой разбор запроса по ключевым словам.
- **Демо-данные** для показа: `python -m app.seed` (6 групп с пометкой [Демо]), удалить — `python -m app.seed --clear`.

## Запуск на своём компьютере

Нужно: Python 3.11 или новее ([python.org](https://www.python.org/downloads/)), токен бота и ваш Telegram ID.
Ключ Anthropic — по желанию (без него работает простой разбор запросов).

1. Создать бота у [@BotFather](https://t.me/BotFather): `/newbot` → получить токен и юзернейм.
2. Узнать свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. В терминале, в папке `coverbot`:

   macOS / Linux:
   ```bash
   python3 -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   ```
   Windows (PowerShell):
   ```powershell
   py -m venv .venv; .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   copy .env.example .env
   ```
   Если PowerShell не даёт активировать окружение: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.
4. Открыть `.env` в любом редакторе и вписать `BOT_TOKEN`, `BOT_USERNAME`, `ADMIN_IDS`
   (и `ANTHROPIC_API_KEY`, если есть). Остальное уже настроено: база — файл `coverbot.db` в папке проекта.
5. Запустить:
   ```bash
   python -m app.seed    # один раз: 6 демо-групп для проверки поиска
   python -m app.main    # бот работает, пока открыт терминал; остановить — Ctrl+C
   ```
6. Открыть бота в Telegram → /start.

В следующий раз: открыть терминал в папке `coverbot`, активировать окружение (`source .venv/bin/activate`
или `.venv\Scripts\Activate.ps1`) и `python -m app.main`.

Пока бот запущен на компьютере, он отвечает, только когда компьютер включён и терминал открыт. Незаконченные
анкеты сбрасываются при перезапуске бота (в облаке их хранит Redis). Anthropic API из России недоступен —
с компьютера в РФ ключ заработает только через VPN, иначе оставьте `ANTHROPIC_API_KEY` пустым.

Тесты: `pytest -q`.

## Перенос в облако (≈10 минут)

Нужно: VPS с Docker (1 ГБ RAM достаточно). Токен бота и Telegram ID — те же, что на компьютере;
ключ API: https://console.anthropic.com → API Keys.

Перед переездом:
- остановить бота на компьютере — один токен нельзя запускать в двух местах одновременно (Telegram отдаёт
  сообщения только одному, второй получит ошибку `Conflict`);
- анкеты, лиды и поиски из `coverbot.db` в облачный Postgres сами не переедут — их нужно перенести отдельно.

1. На сервере:
   ```bash
   # загрузить папку проекта (scp / git), затем:
   cd coverbot
   cp .env.example .env
   nano .env                       # BOT_TOKEN, BOT_USERNAME, ADMIN_IDS, ANTHROPIC_API_KEY
                                   # (базу и Redis docker-compose подставит сам)
   docker compose up -d --build
   docker compose exec bot python -m app.seed    # демо-группы для показа
   docker compose logs -f bot                    # проверить, что стартовал
   ```
2. Открыть бота в Telegram → /start.

Обновление после правок: `docker compose up -d --build`. Незаконченные анкеты и поиски хранятся в Redis
и переживают перезапуск бота (брошенные удаляются через 30 дней).
Импорт: положить CSV в `./data/` → `docker compose exec bot python -m app.importer data/tutvse.csv`.

## Изменение схемы БД

Схема ведётся миграциями Alembic (`migrations/`), бот применяет их сам при старте. Поменяли модель в `app/db.py` →
```bash
alembic revision --autogenerate -m "что поменялось"   # проверить файл в migrations/versions/
```
и закоммитить миграцию вместе с моделью (`tests/test_migrations.py` упадёт, если забыть). База, созданная ранее
через `create_all`, подхватывается автоматически, данные сохраняются.

## Важно про сервер и Anthropic API

Anthropic API недоступен из некоторых регионов, включая Россию. Варианты: сервер в поддерживаемой стране,
или сервер в РФ + прокси к API (`ANTHROPIC_BASE_URL`). В нейросеть уходят только текст запроса продюсера
и карточки групп без контактов; сами персональные данные (контакты, Telegram ID) хранятся в вашей БД.
Если база должна жить в РФ (152-ФЗ), это сочетание — БД в РФ, API через прокси — рабочее.

## Структура

```
app/
  main.py          запуск бота (polling)
  config.py        настройки из .env
  db.py            модели: bands, producers, search_requests, leads, recommendations; миграции при старте
  dictionaries.py  жанры, услуги, инструменты, составы, форматы — правьте здесь
  criteria.py      модель критериев поиска + запасной разбор без нейросети
  llm.py           промпты и вызовы Claude: разбор запроса, пояснения к выдаче
  matching.py      фильтр и скоринг (веса в WEIGHTS)
  cards.py         тексты карточек
  keyboards.py     кнопки
  handlers/        start (меню, ссылки импорта), onboarding (анкета), search (поиск), admin
  importer.py      импорт CSV «Тут все»
  reminders.py     напоминания группам подтвердить цены
  seed.py          демо-группы
migrations/        миграции схемы БД (Alembic)
tests/             pytest: разбор сумм, подбор, запасной парсер, данные FSM, миграции
```
