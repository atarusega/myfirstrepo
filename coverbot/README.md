# Бот подбора кавер-групп — MVP

Telegram-бот: продюсер описывает задачу своими словами → получает 3–5 подходящих кавер-групп с ценой и видео.
Группы сами заполняют анкету, админ модерирует. ТЗ — в документе «ТЗ: Telegram-бот подбора кавер-групп (MVP)».

## Что уже работает

- **Анкета группы** (16 шагов, в основном кнопками): название, город, выезд, состав, инструменты, жанры, описание,
  цены «от» для частного события / корпоратива / Нового года, формат программы, звук, доп. услуги, видео, контакты,
  превью карточки, согласие на публикацию → модерация.
- **Поиск для продюсера**: свободный текст → разбор нейросетью (Claude Haiku) → уточнение города и бюджета кнопками →
  фильтр + скоринг → карточки с пояснением «почему подходит» → «Показать контакт» (лид) → «Рекомендую».
  Любое следующее сообщение уточняет запрос («подешевле», «а на Новый год?»).
- **Если ничего не нашлось** — бот показывает ближайшие по цене варианты или снимает требование к инструментам.
- **Админ** (ID из `ADMIN_IDS`): новые анкеты приходят с кнопками «Одобрить / Отклонить»,
  команды `/pending`, `/stats`, `/export` (CSV всей базы), `/tvrec <id> [tg_id]` — рекомендация резидента «Тут все».
- **Импорт «Тут все»** (по договорённости с владельцем): `python -m app.importer data/tutvse.csv` →
  черновики + `data/invite_links.csv` с персональными ссылками. Музыкант переходит, дозаполняет, даёт согласие.
- **Без ключа Anthropic** бот тоже работает: включается простой разбор запроса по ключевым словам.
- **Демо-данные** для показа: `python -m app.seed` (6 групп с пометкой [Демо]), удалить — `python -m app.seed --clear`.

## Запуск на сервере (≈10 минут)

Нужно: VPS с Docker (1 ГБ RAM достаточно), токен бота, ваш Telegram ID, ключ Anthropic API.

1. Создать бота у [@BotFather](https://t.me/BotFather): `/newbot` → получить токен и юзернейм.
2. Узнать свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Ключ API: https://console.anthropic.com → API Keys.
4. На сервере:
   ```bash
   # загрузить папку проекта (scp / git), затем:
   cd coverbot
   cp .env.example .env
   nano .env                       # BOT_TOKEN, BOT_USERNAME, ADMIN_IDS, ANTHROPIC_API_KEY
   docker compose up -d --build
   docker compose exec bot python -m app.seed    # демо-группы для показа
   docker compose logs -f bot                    # проверить, что стартовал
   ```
5. Открыть бота в Telegram → /start.

Обновление после правок: `docker compose up -d --build`.
Импорт: положить CSV в `./data/` → `docker compose exec bot python -m app.importer data/tutvse.csv`.

## Локальный запуск без Docker

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # и в .env: DATABASE_URL=sqlite+aiosqlite:///./coverbot.db
python -m app.seed
python -m app.main
```
Тесты: `pytest -q`.

## Важно про сервер и Anthropic API

Anthropic API недоступен из некоторых регионов, включая Россию. Варианты: сервер в поддерживаемой стране,
или сервер в РФ + прокси к API (`ANTHROPIC_BASE_URL`). В нейросеть уходят только текст запроса продюсера
и карточки групп без контактов; сами персональные данные (контакты, Telegram ID) хранятся в вашей БД.
Если база должна жить в РФ (152-ФЗ), это сочетание — БД в РФ, API через прокси — рабочее.

## Структура

```
app/
  main.py          запуск бота (polling)
  config.py        настройки из .env
  db.py            модели: bands, producers, search_requests, leads, recommendations
  dictionaries.py  жанры, услуги, инструменты, составы, форматы — правьте здесь
  criteria.py      модель критериев поиска + запасной разбор без нейросети
  llm.py           промпты и вызовы Claude: разбор запроса, пояснения к выдаче
  matching.py      фильтр и скоринг (веса в WEIGHTS)
  cards.py         тексты карточек
  keyboards.py     кнопки
  handlers/        start (меню, ссылки импорта), onboarding (анкета), search (поиск), admin
  importer.py      импорт CSV «Тут все»
  seed.py          демо-группы
tests/             pytest: разбор сумм, подбор, запасной парсер
```

## Ограничения MVP и что дальше (задачи для Claude Code)

- Состояние диалогов хранится в памяти: при перезапуске бота незаконченная анкета сбрасывается.
  Дальше — Redis (`RedisStorage`).
- Смысловой поиск упрощён (пересечение слов). Дальше — эмбеддинги + pgvector (поле уже заложено в ТЗ).
- Голосовые сообщения пока не распознаются.
- Таблицы создаются при старте (`create_all`). При изменении моделей — перейти на Alembic.
- Нет напоминания группам раз в 90 дней подтвердить цены (поле `prices_confirmed_at` уже есть).
