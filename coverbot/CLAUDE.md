# CLAUDE.md — контекст проекта для Claude Code

## Что это
MVP Telegram-бота подбора кавер-групп для ивент-продюсеров. Две стороны:
- продюсер пишет запрос свободным текстом → бот разбирает его нейросетью, уточняет город/бюджет, выдаёт 3–5 групп;
- кавер-группа заполняет анкету → модерация админом → карточка в поиске.
Главная метрика — «Показать контакт» (таблица leads). Партнёрство с сообществом «Тут все»: импорт их базы
(только с согласия владельца) + метки доверия «Резидент Тут все» / «Рекомендуют резиденты».

## Стек и команды
Python 3.12, aiogram 3 (polling), SQLAlchemy 2 async, PostgreSQL (SQLite локально), Redis для FSM
(`REDIS_URL`; пусто — `MemoryStorage`), Anthropic API (Claude Haiku 4.5).
- Сейчас бот работает на компьютере владельца (SQLite, без Redis, polling); облако — позже.
- Локально: `pip install -r requirements.txt`, `cp .env.example .env` (по умолчанию SQLite), `python -m app.main`
- Демо-данные: `python -m app.seed` (`--clear` удалить)
- Тесты: `pytest -q` — держать зелёными
- Миграция после правки моделей: `alembic revision --autogenerate -m "..."` (применяется при старте бота)
- Прод: `docker compose up -d --build`

## Устройство
- `app/dictionaries.py` — все справочники (жанры, услуги, инструменты…). Коды латиницей хранятся в БД.
- `app/db.py` + `migrations/` — модели и миграции Alembic; `init_db` доводит схему до head, базу от `create_all` помечает baseline.
- `app/criteria.py` — модель критериев поиска + `fallback_parse` (работает без API-ключа).
- `app/llm.py` — промпты и вызовы Claude. Любая ошибка LLM → fallback, бот не падает.
- `app/matching.py` — чистые функции: жёсткий фильтр → скоринг (веса в `WEIGHTS`). Тестировать без БД.
- `app/handlers/onboarding.py` — анкета: один FSM-state + таблица `STEPS` (добавить поле = строка в STEPS + колонка в `Band`
  + миграция).
- `app/handlers/search.py` — поиск; после выдачи любое сообщение продюсера уточняет запрос.
- `app/handlers/admin.py` — модерация и команды админа (фильтр по `ADMIN_IDS`).
- `app/reminders.py` — фоновая задача: раз в 90 дней просит группы подтвердить цены (`needs_price_reminder` — чистая функция).
- Данные FSM (`state.update_data`) хранятся в Redis как JSON: только str/int/bool/None/list/dict,
  без datetime и объектов моделей (`tests/test_storage.py`).

## Правила
- Интерфейс бота и тексты — на русском, HTML parse mode, пользовательский ввод экранировать (`html.escape`).
- Нейросеть не выбирает группы сама: только разбор запроса и пояснения. Факты — только из карточки.
- Импортированные карточки не попадают в поиск без согласия музыканта и модерации.
- Персональные данные (контакты, tg id) не отправлять в LLM.
- В миграциях серверные дефолты — `sa.func.now()`, не `sa.text('now()')` (autogenerate на Postgres пишет второе,
  а SQLite такой функции не знает).
